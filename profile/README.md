# HuldLabs

Ferramentas para construir software em times pequenos: um método de trabalho (**Tars**), um design system
(**Tomo**), frameworks por stack (**Sofon**, **Pion**) e a gestão do trabalho (**Kipp**).

O README do ecossistema, o backlog da organização e as decisões transversais moram em
[**HuldLabs/huldlabs**](https://github.com/HuldLabs/huldlabs).
